# Tutorial completo — castellano de España

Esta versión reproduce el tutorial inglés aprobado, pero utiliza **la interfaz española real** de Strategic Resilience Intelligence, narración y subtítulos en **castellano de España**.

- Guion: `chapters.json`, 7 capítulos y 82 fragmentos sincronizados.
- Voz local: Piper `es_ES-davefx-medium`, identificación `es_ES` y datos de entrenamiento CC0.
- Grabación: Playwright, clics reales y comprobación de que el navegador muestra «Investigar», «Comprobar» y «Traducir».
- Validación numérica: 50 días con 75 % de viabilidad y 36,8 días con 90 %.
- Montaje: 1920 × 1080, subtítulos de dos líneas como máximo en una franja debajo de la aplicación.
- Archivos de salida: `ASRI_Tutorial_Completo_Castellano_ES.mp4`, `subtitles.srt`, `voice-credits.txt`, `tutorial-report.json` y PDF/JSON de ejemplo.

## Descargar

Abrir [GitHub Actions — Tutorial en castellano](https://github.com/AUG79-droid/airbus-strategic-resilience-intelligence/actions/workflows/tutorial-castellano.yml). Después de una ejecución correcta, descargar el artefacto `ASRI-Tutorial-Completo-Castellano` y extraer el MP4.

No se usan créditos de Work, Codex ni HeyGen. Las herramientas se ejecutan en un servidor efímero de GitHub; los archivos `app/` y el tutorial inglés permanecen intactos.

**Nota:** Las cifras pertenecen al escenario didáctico; la grabación no demuestra beneficios específicos de Airbus.
