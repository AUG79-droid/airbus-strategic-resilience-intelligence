# Airbus Strategic Resilience Intelligence

An independent, evidence-aware prototype for investigating when sustainability initiatives may contribute to strategic resilience, operational continuity and defensible customer value.

The initial practical case compares replacement, repair-first and parallel strategies for the recovery of a fictional aerospace component. All scenario timings, probabilities, costs and environmental factors are editable fictional examples. They are not Airbus programme, supplier or contractual data.

> **PROTOTYPE — NOT INTERNALLY VALIDATED**
>
> This independent concept is not an Airbus product or an approved operational model. Modelled results are not demonstrated environmental, operational or customer benefits.

## Application

The React + TypeScript + Vite application is contained in `app/` and provides:

- a bilingual guided journey through Investigate, Challenge, Validate and Translate;
- transparent repair, replacement and parallel-strategy calculations;
- sensitivity, threshold, environmental-mechanism and uncertainty analysis;
- an evidence register and claim-gating controls;
- audience-specific strategic translation;
- reproducible JSON and professional PDF exports.

## Local development

```bash
cd app
npm ci
npm test
npm run dev
```

Build the production bundle with:

```bash
cd app
npm run build
```

Hash-based navigation is used so every application section remains compatible with GitHub Pages.

## Evidence and data boundary

The application uses public sources only where explicitly identified. Public context does not validate the fictional component strategy or its modelled inputs. Blocked, unsupported or rejected claims are not exported as demonstrated benefits.


## Create Your Own Strategic Case — GTS case studio

In the published application, select **Create your own strategic case / Crear tu propio caso estratégico** at the top. This journey is separate from the original DEMO-60 module-recovery simulation, and follows all four stages:

1. **Investigate:** frame the specific initiative, strategic vulnerability, baseline, boundaries and decision. Start from scratch or load one of four fully fictional examples (Eurodrone eco-design, product climate adaptation, SAF, wildfire response).
2. **Challenge:** edit the model-specific KPIs, supply three like-for-like options, trace sources per value, compare absolute and relative differences, and explore a user-selected sensitivity margin. The tool is a **transparent multi-criteria comparator**, not a calibrated predictor, approved availability model, certified LCA or environmental guarantee.
3. **Check:** enter documentary reference IDs, sources, owners, reviewers, reviewed dates, observations/estimates, statuses and limitations. Link sources to individual measurements and inspect blockers. Ticking a review gate is an explicit user declaration, not independent validation.
4. **Translate:** generate case-dependent, audience-specific narratives for Defence Customer, Engineering, Programme Manager and Executive Leadership. Download a draft report in PDF or Markdown and save/restore the underlying case as local JSON.

**All four supplied examples contain invented numbers, with no pretence that they originate from Airbus or its customers.** Their numbers are not mixed with DEMO-60. Switching an example to a real-data template clears its numerical inputs and evidence.

### Handling sensitive information

This is an independent public GitHub Pages prototype with browser-session inputs and no ASRI account-based access controls or server-side evidence storage. **Never paste Airbus-confidential material, customer data, internal documents or personal information into this public demonstration.** Only public or anonymised data are appropriate until a corporate deployment is authorised. The model computes numerical comparisons only; it does not automatically approve benefits or prove causal impact.
